# FRAMELESS4K — Premium Wall Showcase

A lightweight static HTML/CSS/JavaScript presentation for showing an edited photograph as premium frameless 4K wall art.

## Run
Open `index.html` in a browser.

## GitHub Pages
1. Create a repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. In GitHub: Settings → Pages.
4. Select the main branch and root folder.
5. Save and open the generated Pages URL.

## Replace the artwork
Replace `assets/hero-wall-display.png` with your own image while keeping the same filename, or change the image paths in `index.html`.

Note: the supplied showcase image is a presentation mockup, not a guarantee that the source photograph itself is native 4K.
